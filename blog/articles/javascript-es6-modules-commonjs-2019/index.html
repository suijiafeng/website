小结

CommonJS 更常见于 Node 和配置脚本，ES6 Module 更适合前端业务代码和静态分析。

面试问模块化，通常会问 require 和 import 的区别、默认导出和命名导出、循环依赖、动态 import、tree shaking。项目里真正要注意的是：模块边界要清楚，导出方式要统一，不要让循环依赖慢慢长出来。
