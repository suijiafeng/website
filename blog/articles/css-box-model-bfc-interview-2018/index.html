盒模型和 BFC：CSS 面试题背后，其实是布局边界

2018-07-26
CSS前端基础

CSS 面试里经常问盒模型和 BFC。

这两个概念听起来偏理论，但写页面时几乎天天遇到。为什么设置了宽度还被撑开？为什么两个 margin 合并了？为什么父元素包不住浮动子元素？这些都和布局规则有关。

什么是 BFC

BFC 可以理解成一个独立的布局区域。里面的元素布局不会影响外面，外面的浮动也不会影响里面。

常见触发方式：

  • overflow: hidden
  • display: flow-root
  • float 非 none
  • position: absolute
  • display: inline-block

老项目里最常见的是 overflow: hidden。

不要滥用 overflow hidden

overflow: hidden 能触发 BFC，但也会裁剪内容。

如果里面有下拉菜单、阴影、浮层，可能被裁掉。用它之前要确认没有溢出内容需要展示。

能用 clearfix 解决清浮动时，不一定非要用 overflow。

小结

盒模型决定元素尺寸怎么算，BFC 决定布局边界怎么隔离。

面试问这些，是因为它们能解释很多 CSS “看起来奇怪”的现象：宽度被撑开、margin 合并、父元素高度塌陷、浮动影响布局。理解规则以后，写布局会少很多猜测。
