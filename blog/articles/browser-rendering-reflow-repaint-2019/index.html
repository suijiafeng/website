浏览器渲染流程：重排和重绘为什么会让页面卡

2019-10-12
前端基础性能与缓存

页面卡顿时，很多人第一反应是 JavaScript 写多了。

这当然可能，但浏览器渲染本身也会消耗时间。DOM 变化、样式计算、布局、绘制，每一步都可能让页面变慢。面试问重排和重绘，背后其实是在问你是否理解浏览器如何把代码变成屏幕上的像素。

从 HTML 到页面

浏览器大致会做这些事：

  1. 解析 HTML，生成 DOM 树
  2. 解析 CSS，生成 CSSOM 树
  3. 合成渲染树
  4. 计算布局
  5. 绘制
  6. 合成显示

DOM 描述结构，CSSOM 描述样式。两者结合后，浏览器才知道每个元素长什么样、放在哪里。

什么是重排

重排也叫 reflow，指的是布局计算重新发生。

会触发重排的操作包括：

  • 修改元素宽高
  • 修改 margin、padding
  • 改变字体大小
  • 添加或删除 DOM
  • 改变窗口大小
  • 读取某些布局属性

小结

浏览器渲染不是黑盒。DOM、CSSOM、布局、绘制、合成每一步都有成本。

面试问重排和重绘，是因为它们能解释很多页面卡顿。项目里要少做无意义 DOM 操作，避免读写布局交错，批量修改节点，动画优先考虑 transform 和 opacity。
