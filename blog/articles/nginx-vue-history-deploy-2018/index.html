Vue history 模式部署：本地能打开，不代表线上刷新不 404

2018-10-16
Vue构建与模块化

Vue Router 默认 hash 模式最省心，URL 里带 #。切到 history 模式后，地址变好看了，但部署问题也来了。

本地开发服务器能打开 /user/list，线上直接刷新却 404。这不是 Vue Router 坏了，而是服务器不知道这个路径应该返回 index.html。

注意 /api/ 和 proxy_pass 后面的斜杠会影响转发路径。这个坑很常见，联调时要看后端实际收到的 URL。

错误页不要影响接口

try_files 应该只用于前端页面路径，不要把接口 404 也回退到 index.html。

否则前端请求接口失败时，可能拿到一段 HTML，JSON 解析报错，排查会很绕。

接口和页面路径要分开配置。

小结

Vue history 模式上线的关键是服务器回退。刷新 404、二级目录资源错、缓存不更新、接口被回退，都是常见问题。

本地能跑只是第一步。真正上线前，要把 Nginx 路径、publicPath、router base、缓存策略一起检查。
