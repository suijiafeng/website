Element UI 后台表单整理：真正麻烦的是校验和回显

2018-03-19
Vue前端基础

后台系统里最常写的不是图表，也不是复杂动画，而是表单。

Element UI 把输入框、选择器、日期、弹窗都准备好了，做一个表单很快。但表单真正麻烦的地方不在组件长什么样，而在校验、回显、异步数据和提交状态。

校验规则要贴近业务

提交要防重复

按钮：

后台接口慢一点时，重复点击很常见。前端应该挡住重复提交，后端也要保证幂等或唯一性校验。

重置表单要小心

Element UI 的 resetFields 会回到初始值。编辑页如果在数据回显前就渲染表单，初始值可能是空对象，后续重置会变成空。

更稳的做法是等详情加载完成后再显示表单：

或者自己维护初始值副本。

小结

Element UI 让后台表单搭起来很快，但表单质量取决于细节：字段结构明确、编辑回显稳定、校验贴近业务、异步选项有 loading、提交防重复、错误提示统一。

表单不是把组件摆上去就完了，它是后台系统里最容易积累边界问题的地方。
