CSS transition 入门：实现简单的滑入滑出效果

2018-12-20
前端基础CSS

CSS transition 是最常用的动画能力之一。

它适合处理简单状态变化，比如 hover、展开收起、透明度变化、滑入滑出。

理解它的关键是：先有状态变化，再有过渡动画。

也就是说，transition 本身不会创造状态。它只负责把一个已经发生的样式变化，变得更平滑。

transition 做了什么

如果一个元素的样式从 A 变成 B，默认会瞬间完成。

加上 transition 后，浏览器会在 A 和 B 之间生成平滑过渡。

当 .box 增加 active 类时，就会向右平滑移动。

这里的两个状态很明确：

  • 默认状态：transform: none
  • 激活状态：transform: translateX(100px)

如果没有这两个稳定状态，动画就会变成“调参数”。写过渡前先把状态想清楚，后面会省很多事。

优先使用 transform 和 opacity

并不是所有 CSS 属性都适合做动画。

通常更推荐过渡：

  • transform
  • opacity

它们更容易被浏览器优化。

像 width、height、top、left 这类属性可能触发布局计算，复杂页面里要谨慎使用。

小结

transition 适合做简单、明确的状态过渡。

写动画前先想清楚两个状态，再选择合适的属性。滑入滑出这类效果，优先使用 transform，性能和体验通常都更稳。

真正可维护的过渡动画，还要处理遮罩点击、焦点提示、透明层拦截、减少动态效果等细节。
