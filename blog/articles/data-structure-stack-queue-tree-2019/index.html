栈、队列和树：前端面试里的数据结构不是白问的

2019-07-16
JavaScript

数据结构听起来像算法课，但前端项目里也经常用。

括号匹配、面包屑、菜单树、组织架构、任务队列、路由层级，这些都不是单纯页面样式问题。面试问栈、队列和树，是因为它们确实能解释很多业务结构。

栈

栈的特点是后进先出。

最常见例子是浏览器历史、函数调用栈、撤销操作。

队列

队列的特点是先进先出。

任务排队、消息队列、请求并发控制都可以用队列思路。

比如限制同时最多 3 个请求，就要维护等待队列和运行中的任务。
