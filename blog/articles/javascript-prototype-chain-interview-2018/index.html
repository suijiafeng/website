JavaScript 原型链：为什么面试总喜欢从 prototype 问起

2018-02-06
JavaScript前端基础

原型链也是前端面试的常客。

很多人平时写业务时不直接碰 prototype，尤其是用了 Vue、React 之后，组件写法已经把很多细节藏起来了。但只要接手工具库、老代码、插件扩展，还是会遇到构造函数、原型方法和继承。

原型链不是为了背概念，而是为了理解 JavaScript 对象是怎么找属性的。
