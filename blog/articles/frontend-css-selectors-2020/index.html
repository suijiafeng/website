CSS 选择器整理：写样式之前，先把元素选对

2020-12-15
前端基础

CSS 里最基础的一步，其实不是写什么样式，而是先把元素选对。

如果选择器本身理解不清楚，后面写出来的样式很容易出现：

  • 命中了不该命中的元素
  • 优先级不好控制
  • 结构一变样式就失效

所以选择器虽然基础，但值得认真整理一下。

我对选择器的重视，是后来维护老页面时被逼出来的。很多样式问题并不是某个属性写错了，而是选择器一开始就选得太宽、太深、太依赖结构。页面还能显示，但每改一处都怕影响别处。

所以选择器不是越精确越好，而是要在清晰和可维护之间平衡。

选择器也是边界设计

写 CSS 时，我会问自己三个问题：

  • 这个样式应该影响哪个组件
  • 结构变一层后它还应该生效吗
  • 后面别人覆盖它会不会很痛苦

这三个问题比“这个属性怎么写”更重要。属性错了好改，边界错了会慢慢渗透到整个页面。

写在最后

CSS 选择器看起来只是基础语法，但它直接决定了样式命中范围和后期维护成本。

写样式之前，先把元素选对，比后面不断修补覆盖更重要。基础打稳之后，很多样式问题其实一开始就可以避免。

我现在写选择器，最看重的不是“能不能命中”，而是“会不会误伤”和“以后好不好改”。CSS 维护久了就会明白，选得克制，比选得复杂更难也更重要。
