深入理解 CSS Grid 布局

2023-08-20
杂项

CSS Grid 是现代 CSS 里最适合做二维布局的工具。和 Flexbox 更偏向一维排列不同，Grid 可以同时处理行和列，因此非常适合页面骨架、卡片列表、仪表盘、图片墙和复杂表单。

很多人学 Grid 时只记住了 display: grid 和 repeat(3, 1fr)，但真正写项目时，还需要理解轨道、间距、区域命名、自适应列和内容溢出这些细节。

Grid 适合解决什么问题

如果你只需要让几个按钮横向排列，Flexbox 通常更简单。如果你需要控制“这一块占两列，那一块固定宽度，主内容自适应”，Grid 会更自然。

可以简单这样判断：

  • 一行或一列内部对齐：优先 Flexbox
  • 同时控制行和列：优先 Grid
  • 页面整体布局：优先 Grid
  • 小组件内部图标和文字排列：优先 Flexbox

两者不是竞争关系。真实项目里经常是外层用 Grid 做结构，内层用 Flexbox 做对齐。

auto-fit 和 auto-fill 的区别

auto-fit 和 auto-fill 很像，但表现不完全一样。

auto-fill 会尽可能创建可用列，即使某些列没有内容；auto-fit 会把空列折叠掉，让已有项目占满空间。

响应式布局中重新排列区域

Grid 的一个优势是可以在不同屏幕下重新安排区域。

桌面端侧边栏在左侧，移动端可以放到正文后面。这样不需要改 HTML 结构，只调整 CSS 布局。

不过要注意可访问性和阅读顺序。CSS 可以改变视觉顺序，但键盘焦点和屏幕阅读器通常仍然按 DOM 顺序走。不要为了视觉布局，把重要内容在 DOM 中放到不合理的位置。

Grid 和 Flexbox 结合使用

Grid 适合整体结构，Flexbox 适合局部对齐。

外层仪表盘使用 Grid 控制侧栏和内容区，工具栏内部使用 Flexbox 控制标题、筛选器和按钮。这种组合比强行只用一种布局方式更自然。

写在最后

CSS Grid 的价值不只是“可以写三列布局”，而是让页面结构变得清晰、稳定、可响应。

掌握 fr、minmax、auto-fit、区域命名、跨行跨列和溢出处理之后，很多原本需要复杂嵌套和媒体查询的布局都能写得更直接。实际项目里，把 Grid 用在页面骨架和二维结构上，把 Flexbox 用在局部一维对齐上，通常是最舒服的组合。
