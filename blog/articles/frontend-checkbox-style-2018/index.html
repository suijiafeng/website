CSS 美化 checkbox：保留语义，比完全模拟更稳

2018-05-10
前端基础CSS

浏览器默认的 checkbox 样式比较朴素。

很多项目会希望把复选框做得更符合设计稿，比如换颜色、加图标、调整大小。

美化 checkbox 有很多方法，但最重要的是不要丢掉它原本的表单语义。

真正稳定的 checkbox 不是“看起来像复选框”，而是鼠标能点、键盘能切换、表单能提交、读屏软件能理解。

不建议只用 div 模拟

有些实现会完全不用 input，只用 div 或 i 模拟复选框。

这种方式虽然看起来灵活，但会带来问题：

  • 表单语义丢失
  • 键盘操作不自然
  • 可访问性变差
  • 表单提交需要额外处理
  • 状态同步更容易出错

除非有很特殊的需求，否则不建议这样做。

小结

checkbox 美化的重点不是把原生控件彻底干掉，而是在保留语义和交互能力的基础上调整视觉。

input + label + :checked 是简单、稳定、可维护的方案，适合大多数业务表单。视觉可以完全定制，但语义、焦点、禁用和提交行为最好继续交给原生控件。
