Vue 动态组件和 keep-alive：后台 tab 页别每次都重新加载

2018-10-28
Vue前端基础

后台系统经常有 tab 页：打开列表，再打开详情，再切回列表，希望筛选条件和滚动位置还在。

如果每次切换都重新创建组件，用户体验会很差。Vue 的动态组件和 keep-alive 正好能处理这类场景。

表单页不一定适合缓存

列表页适合缓存，编辑表单页要谨慎。

如果用户打开编辑 A，再打开编辑 B，组件复用和缓存可能导致数据串。表单页最好用路由参数区分，或者在 beforeRouteUpdate 里重新加载。

小结

keep-alive 能改善后台 tab 体验，但要控制缓存范围。列表页、查询页适合缓存；编辑页、详情页要看参数和状态。

缓存不是越多越好。哪些页面保留状态，哪些页面离开就销毁，应该按业务体验来定。
