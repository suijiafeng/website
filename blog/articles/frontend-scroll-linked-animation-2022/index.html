滚动驱动动画入门：让页面动画跟着滚动走

2022-03-24
前端开发

很多网页都会做滚动相关动画。

比如页面滚动时进度条变长、标题吸顶、图片视差移动、内容逐步出现。

过去这类效果通常依赖 JavaScript 监听滚动位置，再手动修改元素样式。

  • 滚动事件触发频繁
  • 需要节流或 requestAnimationFrame
  • 需要计算滚动距离和页面高度
  • 多个动画会让逻辑变复杂

如果只是让动画进度跟随滚动，CSS 原生能力会更适合。

什么是滚动驱动动画

滚动驱动动画的核心思想是：动画进度不再由时间决定，而是由滚动位置决定。

普通动画是“3 秒内从 0 到 100%”。

滚动动画是“页面从顶部滚到底部时，从 0 到 100%”。

这样用户滚得快，动画就快；用户停下，动画也停下。

适合哪些场景

滚动驱动动画适合：

  • 页面阅读进度条
  • 图片视差效果
  • 内容进入视口时变化
  • 横向滚动展示
  • 长页面中的分段动画

这些效果的共同点是：动画和滚动位置强相关。

使用时要保持克制

滚动动画很容易做得过多。

如果一个页面里每滚动一点都有大量元素移动、旋转、缩放，用户会觉得累，性能也可能变差。

比较好的原则是：

  • 用在关键视觉反馈上
  • 动画幅度不要太夸张
  • 不要影响正文阅读
  • 保留无动画时的基本可用性

动画是增强体验，不应该成为阅读障碍。

小结

滚动驱动动画让 CSS 能直接表达“动画跟随滚动进度”这类关系。

它可以减少一部分滚动监听代码，让进度条、视差和页面动效更清晰。实际项目中仍然要关注浏览器支持，并为关键内容保留稳定的基础体验。
